FOAM GAMING SİTESİ — STATİK ÜRETİCİ (20 Kasım 2026)
====================================================
Sayfalar artık elle düzenlenmiyor. İçerik _build/ klasöründe, sayfalar bir komutla üretiliyor.

KLASÖR
  _build/content.mjs   Oyunlar (TR/EN metinler, paket adı, durum, mağaza linkleri), haberler, site ayarları
  _build/media.py      Mağaza görsellerini/videolarını WebP/MP4'e çevirir → assets/ + _build/media.json
  _build/build.mjs     Tüm .html sayfalarını, en/ klasörünü, sitemap.xml, robots.txt, 404.html üretir
  _build/style.css, _build/site.js   Stil ve script kaynağı (assets/css, assets/js'e kopyalanır)
  _build/legal/        Gizlilik ve veri silme metinleri (TR+EN aynı dosyada)

GÜNCELLEME
  cd foamgaming-site
  node _build/build.mjs          (metin/haber değiştiyse)
  python3 _build/media.py        (yeni görsel/video eklendiyse, önce bu)
  git add -A && git commit -m "site" && git push
  Önbellek sürümü (?v=...) otomatik; elle artırmaya gerek yok.

YENİ OYUN
  1) media.py → GAMES'e ikon, feature, ekran görüntüsü, video yollarını ekle → python3 _build/media.py
  2) content.mjs → GAMES dizisine yeni nesne (tr + en blokları)
  3) node _build/build.mjs
  Ana sayfa kartı, oyun sayfası (TR+EN), menü, footer, basın kiti, sitemap otomatik.
  Oyun yeni bir veri türü topluyorsa _build/legal/privacy.body.html tablosuna satır ekle.

MAĞAZAYA ÇIKINCA
  content.mjs → googlePlay / appStore linkini yaz, status: "live" → build.

HABER EKLEMEK
  content.mjs → NEWS dizisinin en üstüne { date, game, tr:{title,body}, en:{title,body} } → build.

AYARLAR (content.mjs → SITE)
  formEndpoint      "Haber ver" formu. Formspree'de ücretsiz form aç, https://formspree.io/f/XXXX yaz.
                    Boşken form kullanıcının e-posta uygulamasını açar.
  cfAnalyticsToken  Cloudflare Web Analytics token'ı (çerezsiz). Yazılırsa gizlilik sayfasına not eklenir.
  testerGroup       Kapalı test Google Grubu.

Play Console'daki gizlilik / veri silme adresleri değişmedi: /privacy.html, /delete-data.html
